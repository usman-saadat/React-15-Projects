A collection of 15 React projects, from a simple Calendar App to an AI Chatbot and a News & Blogs app. I built these to practice and master modern front-end development with React.

## 📚 What I Learned

- React Hooks (`useState`, `useEffect`, `useRef`, custom hooks)
- Routing with React Router
- State management
- API integration and data fetching
- Authentication forms and validation
- CRUD operations
- Dark/light mode toggle
- Styling with CSS and Tailwind CSS
- Deployment

## ⚙️ How to Run Any Project

1. Clone the repository
   ```bash
   git clone https://github.com/usman-saadat/React-15-Projects.git
   ```
2. Go into a project folder
   ```bash
   cd React-15-Projects/01-Calendar-App
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the dev server
   ```bash
   npm run dev   # or npm start
   ```
